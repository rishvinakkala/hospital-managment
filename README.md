# 🏥 MediCare - Hospital Management System (HMS)

A modern, responsive, and interactive single-page Hospital Management System dashboard built with **HTML5**, **Tailwind CSS**, and **JavaScript**. Designed to streamline hospital administrative tasks such as tracking patients, managing doctors, and handling appointments.

---

## ✨ Features

- **📊 Dashboard Overview:** Real-time summary statistics for Total Patients, Active Doctors, Today's Appointments, and Available Beds.
- **📅 Interactive Appointments:** Dynamic table that displays appointments with status badges (Confirmed, Pending).
- **➕ Add New Appointments:** Modal form allowing users to schedule new appointments which instantly update the dashboard and counter.
- **🔍 Live Search Filtering:** Real-time search functionality to filter appointments by patient name, doctor, or department.
- **📱 Responsive Navigation:** Clean sidebar navigation with mobile support.
- **🎨 Modern Styling:** Styled using Tailwind CSS with FontAwesome icons for a sleek, professional aesthetic.

---

## 🛠️ Tech Stack

- **Markup:** HTML5
- **Styling:** Tailwind CSS (via CDN)
- **Icons:** FontAwesome (v6.4.0)
- **Scripting:** Vanilla JavaScript (ES6+)
